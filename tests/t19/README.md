# T19 — 별도 검사 엔진 관리 WPF 창

T18 엔진 팩 갱신 서비스를 검사 화면에서 분리해 사용합니다. 신규 기능은 현재 활성 검증 팩 정보 표시, 수동 업데이트 조회·승인·진행률, 기존·내장 팩 복원으로 한정합니다. 검사 자체, CSV/HTML 형식, 탐색·제외 정책, 정적 분석 규칙은 변경하지 않습니다.

- `MainWindow`: 검사 입력 영역에 현재 PHPCompatibility/목표 버전 상태와 `엔진 관리…` 버튼만 둡니다. 인라인 다운로드 패널은 제거합니다.
- `EngineManagementWindow`: 현재 `EnginePack`의 PHP CLI/PHPCS/PHPCompatibility/PHPCSUtils·7.4~8.5 지원 목표/한계, 업데이트 조회/비교, 사용자의 확인, 다운로드 바이트 기반 진행률, 설치/검증/재시작 상태, 이전/기본 팩 복원 안내.
- 원격 조회는 사용자가 관리 창에서 요청할 때만 진행합니다. 연결이 없어도 오프라인 엔진 정보는 보이며 검사에는 네트워크가 필요하지 않습니다.
- 관리 창은 모달입니다. 검사 실행 중에는 진입을 잠그고 관리 작업 도중에는 닫기를 막으며 중단 시 요청을 취소합니다. 새로운 팩은 앱 재시작 시에만 사용합니다.
- 다운로드 진행 수치는 수신 ZIP 바이트/카탈로그의 검증된 총 바이트를 사용합니다. ZIP 해시/구성 검증 및 활성화 단계는 수신 진행률과 구분해 안내합니다.
- 기본/최소 WPF 창, 긴 경로, 복사 가능한 제한 문구와 오류 상태를 유지합니다.

## Windows 검증

기존 `tests/t14/GuiCases.cs`를 실제 별도 WPF 관리 창의 수동 다운로드→확인→다음 실행 팩 활성화로 변경합니다. `tests/t14/T14.Verification.csproj`가 Windows에서 서비스/GUI를 함께 시험합니다. `tests/t06`, `tests/t07`, `tests/t12`로 검사 입력·결과·내보내기 회귀를 확인합니다. 통제된 카탈로그 네트워크의 성공과 실제 공개 GitHub 다운로드는 별개이며, 후자는 T20에서만 판정합니다.

**기준:** T17 PHP 7.4~8.5 신규 목표의 실측 통과와 T18 갱신·복원 서비스 통과. 실제 Windows CI가 끝나기 전 이 UI를 완료 처리하지 않습니다.
