# 검증 영역

T01의 자체 작성 [8개 PHP 입력과 사례 정의](fixtures/README.md)를 준비했습니다. 실제 엔진 검사는 아직 수행하지 않았습니다. Windows 명령 초안은 [도구 준비 안내](../tools/probe/README.md)를 따릅니다. 이후 T05/T07/T09에서 계약·원본 불변·Windows 실행을 검증합니다.

원본 보호는 파일뿐 아니라 디렉터리·새 생성물까지 대조합니다. 실제 사용자 프로젝트·비밀정보는 커밋하지 않습니다. PHP fixture는 분석 입력이며 실행하지 않습니다. 검증 보고에는 도구 버전·환경·명령·기대/실제 결과·미검증을 구분합니다.
