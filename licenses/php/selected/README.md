# PHP / Zend에 선택한 후속 조건

2026-11-06 사용자 승인에 따라 covered PHP code에는 PHP License v4, covered Zend Engine code에는 Zend Engine License v3.0 후속 조건을 선택합니다. 적용 조건은 BSD-3-Clause입니다. 자체 프로그램의 MIT 및 독립 내장 라이브러리의 LGPL/기타 조건, Microsoft 바이너리 조건은 바뀌지 않습니다.

`PHP-Zend-BSD-3-Clause.txt`는 공식 https://www.php.net/license/4_0.txt 의 원문 바이트입니다. 이 공통 본문은 PHP Group 및 Zend 양측 저작권을 포함합니다. 별도의 Zend v3 원문인 것처럼 파일을 꾸미지 않습니다. `php-licensing.html`은 공식 https://www.php.net/license/ 페이지의 원문 snapshot이며 Earlier Versions와 Zend v3 설명이 선택의 근거입니다. SHA-256·출처·범위는 [license-election.json](../../../tools/license-audit/license-election.json)에 있습니다.

기존 PHP 3.01/Zend 2.00 원문과 ZIP license/readme 및 원본 source headers는 출처와 독립 조건의 확인을 위해 보존합니다. 이 선택만으로 전체 배포물의 라이선스 적합성을 일괄 보증하거나 공개 Release를 승인하지 않습니다.
